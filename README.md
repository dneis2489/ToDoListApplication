Spring MVC приложение ToDoList

Данное приложение:

    1. Написано на Spring MVC
    2. Обладает простым DAO хранилищем через коллекцию ArrayList
    3. Имеет функции по добавлению, удалению и изменению статусов задач
    4. Реализованы фильтры по активным и завершенным задачам
    5. Реализована статистика отображающая количество активных и завершенных задач
